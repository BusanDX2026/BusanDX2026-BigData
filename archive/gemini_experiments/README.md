# Gemini 모델링 및 시나리오 실험 산출물 (폐기 및 보관)

본 디렉토리는 제미나이(Gemini)가 작성했던 피처 보강 및 강우 시나리오 모델링 실험 스크립트와 결과 리포트를 보관하는 곳입니다.
정밀 교차 검증(Peer Review) 결과, 심각한 물리적 결함 및 성능 열등성이 확인되어 **전량 메인 파이프라인에서 제외(폐기)**되었습니다.

자세한 분석 및 검증 내용은 GitHub Issue [#18](https://github.com/BusanDX2026/BusanDX2026-BigData/issues/18)을 참조하십시오.

## 폐기 사유 요약
1. **강우 시나리오 단조성 붕괴 (치명적)**: 강우량이 100mm → 350mm로 증가함에도 고위험 격자수가 14,274개에서 9,234개로 감소하는 역전 발생 (강우 피처 SHAP -0.48 음수 편향 및 트리 모델 외삽 한계).
2. **피처 중복 및 성능 열등**: M6~M9에서 이미 환경부 세분류 토지피복(불투수율)을 반영하였으며 (당시 PR-AUC 0.2445, 이후 D8 라우팅 수정으로 0.3059), 건물 건폐율(상관계수 0.797)을 얹을 경우 과적합(-3.63%) 유발.
3. **80% 포착선의 행정 비효율**: 80% 포착을 위해 부산시 면적 25%, 인구 77%를 지정해야 하므로 방재 우선순위 무의미.

**공식 최종 파이프라인**: `scripts/모델링/M6` ~ `M9` (M9_최종_확정.py 기준)

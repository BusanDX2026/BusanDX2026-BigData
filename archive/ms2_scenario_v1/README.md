# MS2 활성화 강우 시나리오 v1 (MS3로 대체, 보관)

강우 시나리오 등급의 **1차 버전**입니다. `MS3_활성화강우_관측회귀.py` 가 이를 대체했고,
모든 하류 산출물은 MS3 의 `_v2` 파일만 읽습니다. 경위는 이슈
[#38](https://github.com/BusanDX2026/BusanDX2026-BigData/issues/38).

## 무엇을 했나

격자별 '활성화 강우 등급'(T1 상시취약 / T2 집중호우취약 / T3 극한호우취약 / T0 방어)을 만들어
강우 규모별로 대응 범위가 **누적 확장**되도록 설계했습니다.

핵심 아이디어는 강우 축을 **침수 재발성(recurrence)** 에서 뽑는 것이었습니다.

- 재발 격자(2회 이상 침수): median HAND 0.0m, imperv 0.76 → 약한 비에도 잠김
- 2014 단발 격자: median HAND 0.18m, imperv 0.40 → 극한호우에서만 잠김
- (HAND 차이 Mann-Whitney p=3e-30, MS1 진단)

즉 물리·도시형태 피처로 "이 격자가 재발형인가"를 학습하면 "낮은 강우에 활성화되는가"가 됩니다.
누적 포함(T1 ⊂ T1+T2 ⊂ T1+T2+T3) 구조라 포착률 단조 증가가 구조적으로 보장돼,
제미나이 실험(#18)의 비단조 버그가 원리적으로 불가능합니다. **이 설계는 MS3 가 그대로 계승했습니다.**

## 대체 사유 — 등급 경계가 백분위라 물리적 의미가 없음

| 지표 | MS2 (폐기) | MS3 (채택) |
|---|--:|--:|
| 재발/극한 분리 AUC (전체) | **0.469** — 무작위 이하 | **0.688** |
| 자치구 내부 분리 AUC | 0.621 | — |
| 등급 경계 정의 | 물리결합 점수의 **백분위** | 관측된 **mm/hr 임계** |

MS2 의 활성화 축은 `HAND + TWI + s_phys` 물리 결합 점수였고, 등급은 그 점수의 백분위로 잘랐습니다.
그래서 **"T2 = 몇 mm 인가"를 말할 수 없었습니다.** 행정에 "이만큼 비 오면 여기까지"라고
전달해야 하는데, 백분위 경계로는 그 문장이 안 나옵니다.

MS3 는 S11 이 붙인 **관측 유발강우**(침수흔적 격자의 최대1h mm)를 물리 피처로 회귀 학습해
등급 경계를 측정값으로 정의했습니다.

> 관측: 재발격자 최대1h 중앙 **47mm** vs 2014 단발 **85mm** (S11)

이 차이가 곧 T1/T2 경계의 물리적 근거가 됩니다.

### BUG-1 (높음) — 고령인구가 총인구를 초과

- **증상**: 마스터 격자 281개에서 `pop_65 > pop`, `old_ratio` 최대 **2.25** (비율이 1을 넘음).
- **근본원인**: 내 코드가 아니라 **SGIS 원본의 구조적 불일치**. SGIS는 소수 카운트를 5단위로 반올림·보호처리하므로 `연령별 인구 합 ≠ 총인구(to_in_001)`.
  - 1km 격자 75,070개 중 **4,518개(6.0%)** 에서 `65+ 합 > 총인구`.
  - 예: 총인구 5명인데 65~69세가 10명. 연령합/총인구 비율 중앙값 1.184.
- **내 잘못**: 이 불일치를 검증 없이 통과시키고 절대값을 그대로 배분함.
- **수정**: 65+를 **절대값이 아니라 '연령 내부 비율'** 로 환산 → 총인구에 곱함.
  ```
  old_share = Σ(in_age_014..019) / Σ(in_age_002..019)   # 반올림 편향 상쇄
  pop_65plus = pop_total × old_share                     # 항상 ≤ 총인구
  ```
  + `assert old_ratio ≤ 1`, `assert pop_65 ≤ pop` 를 S5a·S6에 상시 삽입.
- **결과**: `old_ratio` 범위 0.000~1.000, 위반 0건.

### DESIGN-1 — `pop_density` 완전중복

모든 격자 면적이 0.01 km²로 동일하므로 `pop_density = pop × 100`. Spearman r = 1.000, VIF = 1e9.
정보량 0인데 다중공선성만 유발 → **컬럼 제거**. (밀도가 필요하면 모델링에서 파생)

### DESIGN-2 — 지하차도 초희소

지하차도는 점(point)이라 격자 45개(0.055%)에만 값 존재 → 사실상 상수 피처.
**추가**: `underpass_n_300m`(1,262격자), `underpass_n_500m`(3,383격자), `underpass_dist_m`.
모델 입력은 **이웃 피처를 사용**하고 `underpass_cnt`는 식별용으로만.

### FALSE-1 — IDW "범위 이탈"은 오탐

격자 최소 110.17mm가 리포트 표기 지점 최소 110.2mm보다 작아 경보. 정밀 재계산 결과
**지점 실제 최솟값 110.1667**(969 북항), 최댓값 184.8800(296 북부산), 격자 범위 110.17~184.87 → **완전히 내부**.
IDW는 양의 가중치 볼록결합이라 외삽이 원리적으로 불가. 리포트의 반올림 표기가 원인. **코드 정상**.

## 3. 리뷰에서 나온 **방법론적 발견 3건** (모델링에 반드시 반영)

### FIND-1 ⭐ 절대표고 저지대(`lowland5_ratio`)는 부산에서 침수 예측력이 없다

- 전체에서 침수O(0.21) < 침수X(0.23)로 **방향이 역전**.
- **원인**: 부산 저지대(≤5m)의 대부분이 **강서구 12,470격자**(낙동강 삼각주)인데, 여기는 농경지·미개발지라 침수흔적 기록이 거의 없음. 반면 실제 침수흔적은 연제(178)·동래(229)·금정(209)·해운대(231) 등 **표고 10~50m 도심의 국지 저지대**에 집중.
- 강서구 제외 시 +0.035로 방향은 맞으나 여전히 매우 약함.
- **결론: 절대표고가 아니라 상대표고(TPI)가 부산 침수의 지형 설명변수다.** MCDA 가중치·피처 선택에서 `tpi`를 지형 축의 주지표로, `lowland*`는 보조/제외.

### FIND-2 ⚠ 침수흔적(타깃)의 **56.6%가 2014년 단일 호우사건**

연도별 격자 수: 2014년 **1,638** / 2020년 388 / 2021년 179 / 2011년 137 / 나머지 소수.
- 모델이 "2014-08-25형 호우 패턴"에 과적합될 위험.
- **완화책**: ① 2014 제외 홀드아웃으로 일반화 검증 ② `trace_count`(반복 침수)를 보조 타깃으로 병행 ③ 결과 해석 시 "관측 사건 편중" 명시.

### FIND-3 ⚠ 침수흔적도는 "실제 침수"가 아니라 **"기록된 침수"** — 조사 편향 존재

구별 침수흔적 격자: 기장군 **886**(최다) > 강서 317 > 해운대 231 > 동래 229 > 북구 215 > 금정 209 … 부산진 **22**.
- 인구·개발밀도로 설명되지 않는 분포. 지자체별 침수흔적도 작성 성실도·조사 범위 차이가 반영된 것으로 판단.
- **완화책**: 검증 지표를 절대 포착 수가 아니라 **자치구 내 상대순위(Spearman)** 및 **자치구 블록 홀드아웃**으로. 자치구별 편향이 성능 지표를 오염시키지 않도록.

## 6. 모델링(M단계)에 넘기는 결론

1. **`tpi`를 지형 주지표로, `lowland*`는 보조/제외** (FIND-1)
2. **`fluv_area_ratio` 주 피처, `fluv_grade` 보조** (L-1 가정 회피)
3. **완전중복 쌍 정리**: `rain_annmax_mm` ≡ `rain_ratio` 중 1개만. `elev_mean`≈`elev_min`(0.993), `fluv_grade`≈`fluv_area_ratio`(0.997)도 1개씩
4. **인구·건물 9피처는 하나의 '노출' 축** (r 0.7~0.96) → MCDA는 합성 1축, 트리모델은 그대로 가능, 선형해석은 주성분/합성지표
5. **지하차도는 이웃 피처(`underpass_n_300m`) 사용**
6. **검증 설계**: 자치구 블록 홀드아웃 필수 + **2014 제외 홀드아웃** 추가 + 지표는 자치구 내 상대순위(Spearman) 병행 (FIND-2, FIND-3)
7. **`pluv_*`(도시침수)는 강서 전용** — 전역 모델에 넣지 말고 강서 케이스스터디에서만

# S0. 전처리 작업 규약 (확정)

> 이후 모든 전처리(S1~S8)·모델링(M1~M8)은 이 규약을 따른다. 규약 위반 여부를 매 단계 검증한다.
> 확정일: 2026-09-03

---

## 1. 좌표계

- **분석 기준 좌표계: `EPSG:5186`** (Korea 2000 / Central Belt 2010, 중부원점, GRS80 TM)
- 이유: 홍수위험지도·건물통합정보·5m DEM 3개가 이미 5186, 부산 침수 분석의 관례
- **재투영 대상**

| 데이터 | 원본 CRS | → |
|---|---|---|
| SGIS 행정구역·격자 경계 | EPSG:5179 (UTM-K) | 5186 |
| Copernicus DEM 30m (부산 전역 유일 DEM) | EPSG:4326 (WGS84) | 5186 |
| 침수흔적도 | EPSG:3857 (Web Mercator) | 5186 |
| 배수펌프장·CCTV·지하차도(지오코딩)·AWS/ASOS 지점 (위경도) | EPSG:4326 | 5186 |

- 5179↔5186, 4326→5186 재투영은 좌표계 변환일 뿐 왜곡 없음 (모두 GRS80)
- ~~5m DEM(5186)~~ S1에서 폐기 — 받은 파일이 실제 90m·5179였음. DEM은 Copernicus 30m 단일 소스 (`_리포트/S1_무결성.md` §5)
- 최종 산출 지도는 필요 시 5186 유지 or WGS84로 별도 변환본 제공

## 2. 분석 격자

- **100m × 100m fishnet**, CRS EPSG:5186
- **원점 정렬**: 격자 좌하단 X·Y를 100의 배수로 스냅 (부산 경계 bbox를 100m로 내림/올림)
- **격자 범위**: 부산 경계 폴리곤과 `intersects`하는 셀만 (경계 걸친 셀 포함)
- **격자 ID**: `grid_id` = `f"{int(x_min//100)}_{int(y_min//100)}"` (좌하단 100m 인덱스). 중복 불가
- 격자에 `x_cen`, `y_cen`(중심 좌표), `sgg_cd`(중심점이 속한 시군구), `adm_cd`(행정동) 컬럼 보존 → 공간 교차검증·집계용

## 3. 부산 경계

- **외곽 경계**: `01_행정경계_인구_SGIS행정구역/2. 경계/.../bnd_sigungu_00_2025_2Q.shp` 에서 `SIGUNGU_CD` 앞 2자리 **`21`** 필터 → `dissolve` → 단일 (Multi)Polygon
  - ⚠️ **SGIS 경계·격자는 부산을 `21`로 코딩**(SGIS 레거시 시도코드). 다른 데이터(건물 `AL_D010_26`, 홍수위험지도 `SGG_CD 26xxx`, 침수흔적도 `STDG 26`, 재해위험지구 법정동 26)는 전부 **행정표준코드 `26`**.
  - 격자·경계에 붙일 표준 `sgg_cd`(26xxx)는 **구 이름(SIGUNGU_NM) → 표준코드 매핑표**로 부여 (S2에서 dict 생성). SGIS 21xxx ↔ 표준 26xxx 는 뒤 3자리도 달라 이름 매칭 필수.
- **도서 포함**: 가덕도·눌차도 등 부산 소속 도서 포함 (SGIS 경계에 포함되어 있음)
- **행정동 경계**: SGIS `bnd_dong` `ADM_CD` 앞 2자리 `21` 필터 (부산 206개 행정동) → `가공데이터/01_격자/부산_행정동.gpkg` 별도 보관, 최종 집계 단위. 키 = SGIS `ADM_CD`(8자리) + `ADM_NM`. 01 인구통계 CSV·02 격자 CSV도 SGIS 코드 체계라 조인 정합.

## 4. 결측 규칙

| 상황 | 처리 |
|---|---|
| 공간 미포함 — 홍수위험지도 폴리곤 없는 격자, 침수흔적 없는 격자, 지하차도 없는 격자 | **0** (위험/시설 없음을 의미) |
| 관측 결측 — 특정 격자에 강우 관측지점 영향권 없음 등 | **NaN 유지** → 모델 단계(M)에서 보간 또는 제외 결정 |
| 인구·면적 배분 결과 음수 / NaN | **0** |
| DEM no-data 셀 | 마스킹(NaN), 격자 집계 시 유효 셀만 평균 |

## 5. 이상치 규칙

| 지표 | 처리 |
|---|---|
| 침수심(FLDN_DOWA 등) 음수 | 0으로 클리핑 |
| 침수심 과대 (> 10 m) | 개별 확인 후 상한 클리핑 (자연 최대치 고려) |
| 관측 좌표가 부산 bbox 밖 (위경도 이상) | 좌표 무시, 지점ID로만 매칭. (07·12는 지점 자체가 부산이라 해당 없음 — AI-Hub 강우 좌표 이슈 대비 규칙) |
| DEM 해수면 근처 음수 표고 | **유지** (간척지·저지대 실제값). 명백한 오류값(예: < -50m)만 no-data 처리 |
| 강수량 음수 | 0 |

## 6. 정규화 (S 단계 아님 — M1에서 적용)

- 기본: **robust min-max** (5~95 퍼센타일 기준, 범위 밖은 [0,1]로 클리핑)
- 왜도 큰 지표(인구, 연면적, 침수면적): `log1p` 후 robust
- 방향 정렬: **위험↑ → 점수↑** 로 통일 (표고·펌프장 근접 등은 부호 반전)
- S 단계 산출물은 **원값 유지** (정규화는 모델링에서)

## 7. 산출물 규칙

```
가공데이터/
├── 01_격자/           부산_경계.gpkg, 부산_행정동.gpkg, grid_100m.gpkg (fishnet + grid_id·좌표·sgg_cd·adm_cd)
├── 02_레이어별/        <지표군>_grid.parquet  (grid_id + 해당 지표 컬럼들, CRS 메타 주석)
├── 03_마스터/          master_grid.parquet + master_grid.gpkg (모든 지표 grid_id 조인, 격자당 1행)
└── _리포트/            각 S단계 검증 리포트 (행수·결측률·총량보존·CRS 로그)
```

- **파일 포맷**: 벡터 = GeoPackage(.gpkg), 속성테이블 = Parquet, 래스터 = GeoTIFF(5186)
- **키 컬럼명**: 격자 = `grid_id`, 시군구 = `sgg_cd`(5자리), 행정동 = `adm_cd`
- 모든 벡터/래스터 산출물은 **EPSG:5186**

## 8. 재현성

- 스크립트: `scripts/전처리/S{n}_*.py`, 순서대로 실행 시 동일 결과
- 난수 사용 시 `random_state=42` 고정
- 각 스크립트 종료 시 `_리포트/`에 요약(입력 파일·행수·CRS·결측률·총량) 기록
- 인증키·개인정보(생년월일)는 코드에 넣지 않음 (이미 수집 완료, 재수집 스크립트는 placeholder)

## 9. 검증 필수 4대 항목 (매 단계)

1. **CRS**: 조인·오버레이 전 전 레이어 EPSG:5186 확인
2. **총량 보존**: 클립·집계 전후 총인구·총면적·레코드수 대조 (±0.1%)
3. **target leakage**: `danger_level` 미사용, 침수흔적(타깃)과 홍수위험지도(피처) 독립성 명시
4. **공간 자기상관**: 모델 검증은 자치구/블록 홀드아웃 (랜덤 K-fold 금지)

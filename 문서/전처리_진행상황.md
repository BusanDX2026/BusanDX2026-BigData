## S1~S4에서 확정/수정된 사항

1. **[S1] 5m DEM 폐기** — 받은 `DEM_5m_도엽35913.img`가 실제로는 90m·EPSG:5179였음. `_보류_잘못받음_90m_도엽35913/`로 이동. **DEM은 Copernicus GLO-30(30m) 단일 소스**. (S0 §1 재투영표 수정)
2. **[S2] SGIS 경계·격자는 부산을 코드 `21`로 코딩** (SGIS 레거시). 다른 데이터는 전부 행정표준코드 `26`. 표준 `sgg_cd`(26xxx)는 구 이름 매핑으로 부여. (S0 §3 수정)
3. **[S2] 부산 경계 면적 785.6 km²** = 공식 770.1 km² 대비 +2.0%. SGIS 경계가 해안선·매립예정지를 넉넉히 포함. 격자 정의용이라 허용, 수역 셀은 후속 단계에서 제거.
4. **[S2] 홍수위험지도 침수심 = 연속값 아님**. `SEG_CODE` N330~N334 = 침수심 등급 5구간(추론: <0.5m ~ ≥3.0m). 국가하천(7시군구)·지방하천(9시군구) 별도 레이어. **도시침수지도(내수)는 강서구만** 존재.
5. **[S3] DEM 총량 확인** — 유효셀 872,873 × 900m² = 785.6 km² → S2 경계 면적과 정확히 일치. 표고 -10~785m(금정산 대역).
6. **[S4] 격자 81,435셀**, grid_id 유일, 원점 100m 스냅(x0=360700, y0=256000), 전 셀에 sgg_cd·adm_cd 부여(중심점 within + 해안 partial은 최대교차면적 폴백).

## S5 계획 (레이어별 격자 집계 → `02_레이어별/*_grid.parquet`, 키 `grid_id`)

| 지표군 | 방법 | 비고 |
|---|---|---|
| 인구·고령인구 | SGIS 1km → 100m **dasymetric** (건물 연면적 가중 배분), 총량 보존 검증 | 노출·취약 |
| 건물 | 격자별 동수·연면적·지하층 보유 동수·주거 연면적 (AL_D010) | 노출 |
| 하천범람 위험 | 격자별 최대 침수심등급(N330~334), 등급별 면적비 (국가+지방 max) | 위험 |
| 내수(도시침수) | 강서구만 등급/면적비, 그 외 NaN → DEM 저지대로 대체 근거 | 위험(부분) |
| 침수흔적(정답) | 격자별 침수흔적 면적비·최대 침수심·최근 침수연도·발생횟수 | **검증 타깃**(피처 아님) |
| 지형 | 격자별 평균·최저 표고, 경사, 표고≤5m 면적비, (가능시)TWI | 위험 |
| 배수펌프장 | 격자 중심→최근접 펌프장 거리, 500m/1km 내 개소수 | 대응 |
| 지하차도 | 시설명 지오코딩(도로명/브이월드) → 격자 매핑, 격자내 지하차도 수·연장 | 노출/운영대상 |
| 재해위험지구 | 법정동코드→법정동 폴리곤→격자, 유효+침수 20개소 플래그 | **비교 baseline** |
| 강우 | ASOS 2 + AWS 15 지점 연최대 일강수량 → 지점좌표(KMA 메타) → IDW 보간 → 격자값 | 위험 |

**확정된 선택(사용자)**: ① dasymetric = 연면적 가중 ② 강우 = IDW power=2 ③ 침수심 = 등급 순위값 + 면적비 둘 다 ④ 지하차도 = 브이월드 지오코딩.

## S5a~S5d 결과 하이라이트

- **S5a**: 100m 인구 총합 3,276,563 = 1km 원본과 **정확히 일치**(총량보존 ±0.000%). 건물 연면적 손상값 2건(83백만·109만 m²) 정제. 건물 커버리지 불량 1km 셀 67개는 균등배분으로 폴백.
- **S5b 핵심**: 과거 침수흔적 격자 2,893개 중 **하천범람예상도(200년) 범위 안은 39%뿐** → 나머지 61%는 내수·저지대·배수불량. **"기존 위험지도만으론 부산 침수의 60%를 설명 못 한다" = 프로젝트 존재이유를 데이터가 뒷받침.** (면접 질문 대응 근거)
- **S5c**: 저지대(≤5m)가 격자의 22% (강서·사상 삼각주). 경사 중앙값 11°(구릉 도시).
- **S5d**: 격자의 84%가 배수펌프장 1km 밖. 펌프장 배수능력·가동기준 데이터는 없어 거리 근사만.
- **S5g**: 지점 평년 연최대 일강수량 139~185mm, 격자 공간비율 0.69~1.16 (부산평균 159mm). **강우의 공간차등은 작음**(격자 std 5.4mm) → 모델에서 이 피처 중요도는 낮을 것으로 예상(정상, 부산은 좁아 일강수량 분포가 균질). ASOS 재현빈도 크기 결합은 모델링에서.
- **S7**: AI-Hub 내수(danger_level=0) 이미지의 실제 관측지점은 **15곳뿐**(온천천 세병교 일대=연제구 거제·연산동에 집중, 그 외 동구·남구·서구·중구·해운대 산발). 외수(danger_level=1) 25,412장은 좌표 없음. 좌표오류 1건(경도 129.97, 동해상) 제외. → AI-Hub는 citywide 레이어가 아니라 **시범구역 사례분석·모델 검증 앵커**로만 사용. 각 지점→100m 격자·행정동·최근접 방범CCTV(중앙값 80m) 매핑 완료.
- **S8 품질**:
  - 완전 중복(r≈1.00): `pop`≡`pop_density`, `rain_annmax_mm`≡`rain_ratio`, `pluv_grade`≡`pluv_area_ratio`, `fluv_grade`≈`fluv_area_ratio`(0.997), `elev_mean`≈`elev_min`(0.993) → M4에서 쌍별 1개만 사용 (등급/면적비 둘 다 저장한 건 모델이 선택하게 하려는 의도).
  - **인구·건물 9개 피처가 하나의 강한 상관 클러스터**(r 0.7~0.96) = '노출' 단일 축. 사용자가 우려한 다중공선성 실체 확인 → MCDA에선 1축, 트리모델은 영향 작음, 선형해석은 합성지표 필요.
  - log1p 권장 피처 15개(인구·연면적·등급·펌프수). 정규화는 M1.
  - 침수흔적과 단순 Spearman: 전부 |r|≤0.19 (100m·3.6% 양성·공간자기상관). 부호는 상식적(펌프근접+, 건물+, 표고−, 경사−). **강우는 −0.07로 최저** → S5g 예상과 일치. `pluv`(도시침수)는 −0.03 + 76% 결측 → 사실상 무력, 내수는 DEM 저지대·침수흔적으로 대체.
  - target leakage 체크 통과(master에 trace/danger 컬럼 없음), 격자수 81,435 보존.
- **S5e 지하차도**: 브이월드 검색 API로 47/56 지오코딩(84%) → 45격자. 미매칭 9건은 소형·비정형명(굴다리·생태통로·보훈병원1/3 등, 문전교차로 지하차도 제외 대부분 <50m). `_지오코딩결과.csv`로 수기 보완 가능. **지하차도는 point라 격자 피처로는 초희소**(비영 45셀) → 모델링에서 인접 300m 이웃 플래그로 확장 권장.
- **S5f 재해위험지구**: 71건 전부 위치화(지명검색 64 + 구중심근사 7). 지정면적 기반 반경(≤400m) 버퍼로 격자 플래그. **유효+침수 20지구 → 423격자**. baseline_grid.parquet로 분리(피처 아님). 우리 지수 vs 행정지정 대조는 자치구/행정동 단위 우선(구중심근사분 정밀도 한계).

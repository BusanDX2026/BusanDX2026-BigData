## 표기 시 주의

- 제목·본문에 **"예측"·"경보"·"시스템"** 을 쓰지 않는다. **"권고"·"우선순위"·"점검 순서"** 로 쓴다.
- **MS3(활성화 강우)는 부가 참고**다. 회귀 R² 0.242 · 분리 AUC 0.688 로 느슨하므로
  "이 격자는 104mm에 잠긴다"는 격자별 임계 단정을 하지 말고 **상대 순서·광역 밴드**로만 쓴다.
  등급 근거도 구분 표기: 침수이력 2,893격자 = 관측, 나머지 27,335격자 = 추정.
- **119 소방출동은 모델에 채택하지 않았다.** 교차검증에 썼고 부적합 판정했다.
  붙임 4-2 에는 "사용 및 검증 결과"로 쓰되 "성능을 올렸다"고 쓰면 안 된다.

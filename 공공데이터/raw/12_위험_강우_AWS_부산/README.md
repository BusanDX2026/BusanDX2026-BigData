# 12. 방재기상관측(AWS) 일자료 — 강우 공간분포 (부산)

## 데이터 특성
- **형식**: CSV
  - `AWS_일자료_부산_2005-2026_통합.csv` : **100,312행** (10년 단위 3개 병합)
  - 원본: `AWS_일자료_부산_2005_2014.csv` (14지점), `_2015_2024.csv` (15지점), `_2025_2026.csv` (12지점)
- **지점**: **부산 AWS 15개소** (160 부산(레), 296 북부산, 904·910·921·923·937·938·939·940·941·942·950·968·969) — ASOS 2개소(07번) 대비 큰 밀도 향상
- **기간**: 2005-01-01 ~ 2026-08-31 (21년+). 대부분 지점 전 기간, 일부(968·969)는 2010~2020, 296은 2020~
- **⚠️ 2026은 1~8월 부분** → 통계는 완전연도(~2025)만, 2026은 이벤트 컨텍스트용
- **컬럼**: 지점, 지점명, 일시, **일강수량(mm)** — 무강수일 포함 전일 기록
- **비고**: AWS 일자료엔 "1시간·10분 최다강수량" 없음 (그건 ASOS 07번)

## 왜 필요한가
- **위험(Hazard) — 강우 공간분포 레이어**:
  - 07번 ASOS는 2지점뿐 → 자치구 간 강우 차등 불가였음
  - 이 15지점으로 **부산 내부 강우 공간 패턴** 산출 — 지점별 연최대 일강수량 → 공간보간(IDW/크리깅) → "어느 자치구·행정동이 호우 시 상대적으로 비가 많이/적게 오는가"
- **결합 방식**: ASOS(07)로 재현빈도 크기(100년 빈도 = X mm) 산정 → AWS(12)로 그 값의 **공간 비율**을 곱해 격자별 강우 위험 부여
- 다중공선성 우려 대응: 강우는 여전히 "1개 개념" — 공간해상도만 개선. feature 수 안 늘어남 (S8 상관행렬에서 확인)

## 한계·유의사항
- **지점 위경도가 CSV에 없음** → KMA 지점정보(메타데이터)로 각 지점번호 좌표 매칭 필요
- 일부 지점 관측기간 짧음(968·969·296) → 재현빈도보다 상대 공간패턴에 사용
- 일자료라 단시간(1시간) 극한강우의 공간분포는 못 봄 → 그건 ASOS 07번 2지점 + 홍수위험지도로 보완

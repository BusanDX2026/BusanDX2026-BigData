# 09. 부산광역시 방범용 CCTV 정보 — 결합키

## 데이터 특성
- **형식**: CSV (21,060행)
- **주요 컬럼**: 번호, 구군, 구분(설치목적), 관리번호, 시설명칭, **위도, 경도**
- **인코딩**: CP949(EUC-KR)
- **좌표계**: 위경도 (WGS84)
- **기준일**: 2025-12-29

## 왜 필요한가
- **AI-Hub 라벨링 데이터 결합키**: AI-Hub 「침수위험지역 라벨링 데이터」의 CCTV 30개 지점은 폴더명(`{ID}_{자치구}_{지점명}`)만 있고 **좌표가 없음**. 이 데이터의 위경도와 지점명·자치구를 대조해 AI-Hub 30지점에 실좌표를 부여
- 좌표가 붙으면 AI-Hub 세그멘테이션(수면 영역) 결과를 홍수위험지도·저지대·침수흔적과 같은 격자에서 비교 가능 → 시범구역 사례분석
- 부산 CCTV 분포 자체가 도심 활동 밀집도(노출) 보조 지표

## 한계·유의사항
- 방범용 CCTV 위주 → AI-Hub의 하천/재난감시 CCTV(예: `29_금정구_수영강재난감시1`, `94_동래구_온천교`)는 명칭이 정확히 안 맞을 수 있음 → 교통 CCTV(data.go.kr 15034450)·주소 지오코딩으로 보완
- 매칭 실패 지점은 지점명 주소를 직접 지오코딩

- 참고(교통 CCTV): https://www.data.go.kr/data/15034450/openapi.do

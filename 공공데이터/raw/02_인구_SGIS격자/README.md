# 02. 격자 단위 인구·가구·주택 통계 + 격자 경계 (SGIS)

## 데이터 특성
- **형식**: 통계 = CSV, 경계 = SHP
- **구성**
  - `1. 통계/` : 2024년 기준 **1km 격자** 통계 — 인구 / 가구 / 주택 / 사업체·종사자
  - `2. 경계/` : 격자 경계 SHP (`grid_XX` 블록으로 분할: 가다·가라·나나 …)
  - `3. 코드집/` : 행정구역↔격자코드 매핑
- **해상도**: **1km 격자** (100m·500m는 SGIS 포털 별도 신청 필요)
- **커버리지**: 전국. 파일이 격자블록(2글자 코드)으로 분할되어 있어 부산 커버 블록만 추출해 사용
- **좌표계**: EPSG:5179
- **기준시점**: 2024년
- **비고**: 응답자 보호용 비밀보호기법(노이즈) 적용 — 소규모 격자값은 근사치
- **용량**: 279MB (전국)

## 왜 필요한가
- **노출(Exposure) 핵심 레이어**: 침수위험 격자에 "몇 명이 사는가"를 얹는 데이터. 선제대응은 인명 보호가 1순위이므로 인구가 우선순위 지수의 큰 가중치
- 100m 분석격자로 **면적가중 배분**(또는 건물 dasymetric) → 격자별 상주인구 추정
- 주택유형(단독/공동/비주거용)·건축년도 → 반지하·노후주택 밀집(침수 취약) 파악 보조

## 한계·유의사항
- 1km 해상도 → 100m 분석격자보다 거칠다. 배분 시 총량(부산 총인구) 보존 검증 필수
- 야간 상주인구 기준 → 주간·유동인구 차등은 반영 못 함 (한계로 명시, 필요 시 생활인구 데이터 보강)

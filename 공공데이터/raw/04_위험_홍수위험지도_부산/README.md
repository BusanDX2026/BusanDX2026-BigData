# 04. 홍수위험지도 (부산)

## 데이터 특성
- **형식**: SHP (시군구별 zip)
- **좌표계**: EPSG:5186
- **성격**: 실측이 아니라 **시나리오 시뮬레이션** — "설계빈도를 초과하는 홍수가 발생한다고 가정"했을 때의 침수범위·침수심
- **폴더 구성**

| 폴더 | 내용 | 시군구 수 |
|---|---|---|
| `01_국가하천_하천범람_200년/` | 낙동강 본류 범람. 200년 빈도 | 7 (강서·금정·기장·북·사상·사하·해운대) |
| `02_지방하천_하천범람_200년/` | 온천천·수영강·학장천 등 지방하천 범람. 200년 빈도 | 9 (+ 남·동·부산진) |
| `03_도시침수지도_100년/` | **내수(도심) 침수** — 펌프장·저류조 용량초과 가정. 100년 빈도 | 1 (강서구만 — 부산 유일 구축분) |
| `99_참고_유역별_국가하천_낙동강남해/` | 유역(중권역) 단위 버전 (참고용) | — |

- 속성: 빈도별 침수심 구간 면적 (`floodAreaDepthLe05`, `..0510`, `..1020`, `..2050`, `..Gt50`), 시군구코드, 수계코드
- **기준월**: 국가하천 2025-02, 도시침수 2026-02

## 왜 필요한가
- **위험(Hazard) 핵심 레이어**: 격자별 예상 침수심·침수범위 → 우선순위 지수의 위험 항목
- **위험 유형 분해 (선제대응 조치 연결)**:
  - 국가하천 범람 지배 격자 → 하천 통제·제방 점검·대피
  - 지방하천 범람 지배 → 도심 하천변 통제
  - 도시침수(내수) 지배 → 배수펌프 선제가동·빗물받이 청소·차수판
- **면접 대응**: "행정이 지정한 상습침수구역"과 달리 시뮬레이션 기반이라 미기록 지역도 커버 → 재해위험지구 지정과 비교해 사각지대 발굴

## 한계·유의사항
- **내수침수(도시침수지도)가 부산에서 강서구만 구축** → 호우 선제대응의 핵심인 내수침수 위험은 침수흔적도(05) + DEM 저지대(06) + 배수펌프장(08)로 보강
- 극한 시나리오 가정 → 실제 발생확률과 다름
- 라이선스가 변경금지(ND) → 원본 재배포보다 "분석 가공 결과"로 활용, 출처 표기 필수

# 06. 수치표고모델 (DEM) — 지형

## 데이터 특성

### `DEM_30m_Copernicus_부산/` — 부산 전역
- **형식**: GeoTIFF 4타일 (`Copernicus_GLO30_N34_00_E128_00 / N34_E129 / N35_E128 / N35_E129`)
- **해상도**: 30m (Copernicus GLO-30, ESA 전지구 DEM)
- **커버리지**: N34~N35, E128~E129 → **부산 전역(강서구~기장군) 완전 커버**
- **좌표계**: EPSG:4326 (WGS84) → 분석 시 5186 재투영
- **용량**: 약 76MB

### ~~`DEM_5m_국토지리원_도엽35913/`~~ → `_보류_잘못받음_90m_도엽35913/` (전처리 제외)
- **S1 무결성 점검 결과 이 파일은 5m가 아니라 90m·EPSG:5179였음** (264×319px, 24×29km 커버, `DEM_5m_도엽35913.img`)
- 국토정보플랫폼에서 5m가 아닌 **90m 수치표고모델**을 받은 것으로 판단. 90m는 Copernicus 30m보다 거칠어 가치 없음
- **조치**: `_보류_...` 로 이동, 전처리에서 사용하지 않음. DEM은 **Copernicus GLO-30(30m) 전역 단일 소스**로 진행
- 5m 시범 분석이 필요하면 국토정보플랫폼에서 해당 도엽의 **5m 등급**을 재다운로드해야 함
- 상세: `공공데이터/가공데이터/_리포트/S1_무결성.md` §5 [DEM-1]

## 왜 필요한가
- **위험(Hazard) 물리 근거 레이어**:
  - 격자별 평균표고·최저표고 → **저지대** 식별 (호우 시 물이 모이는 곳)
  - **저지대 비율** (격자 내 임계표고 이하 면적) → 격자 단위 침수 노출도
  - 경사도 → 배수 속도 (완경사 = 정체)
  - 흐름누적 / TWI(지형습윤지수) → **물길 집중부** = 내수침수 상습 지점 추정
- 도시침수지도(내수)가 부산 대부분 미구축이므로, DEM 저지대·물길이 **내수침수 위험의 주 대체 근거**
- 5m는 시범구역에서 건물·가로 단위 미세지형 분석

## 한계·유의사항
- **30m는 도심 미세지형(측구·소로) 표현이 약함** → 100m 격자 집계엔 충분(셀당 ~11샘플)하나 건물 단위 분석엔 부족
- Copernicus는 WGS84 → EPSG:5186 재투영 필요. **해수면 = 0m로 채워져 있어** 부산 육지 경계 클립 후 해상 셀 마스킹 필요 (S3)
- 5m DEM 부재 → 건물 단위 미세지형은 이번 범위 밖(100m 격자 분석으로 한정)

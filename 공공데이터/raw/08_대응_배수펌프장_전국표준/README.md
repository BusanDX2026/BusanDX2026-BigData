# 08. 전국 배수펌프장 표준데이터 — 대응역량

## 데이터 특성
- **형식**: CSV (전국 표준데이터, 591행)
- **부산**: 80개소
- **주요 컬럼**: 시설명, 시도명, 시군구명, 소재지도로명주소·지번주소, **위도·경도**, 전화번호, 설치년도, 설치목적
- **좌표계**: 위경도 (WGS84) → 분석 시 5186 재투영
- **갱신주기**: 연 1회 (현재 시설 목록)

## 왜 필요한가
- **대응역량(Capacity) 레이어 — "이미 방어수단이 있는가"**:
  - 격자별 최근접 배수펌프장까지 거리
  - 펌프장 서비스권역(버퍼) 내/외 판정 → **펌프장 없는 저지대 = 선제대응 우선순위 상향**
- **면접 대응**: "과거 침수가 잦았어도 그 뒤 펌프장이 생긴 곳"과 "침수 이력은 적어도 방어수단 없는 신규 위험지"를 구분 → 단순 과거 침수 재확인이 아닌 이유
- 자원배분 관점: 한정된 선제대응 인력을 펌프장 커버 안 되는 곳부터

## 한계·유의사항
- 펌프장 **위치·설치목적**만 있고 **배수능력(용량)·가동기준**은 없음 → 서비스권역은 거리 기반 근사
- 저류시설·차수시설·하수관로 용량은 별도 데이터 없음 → 대응역량 레이어가 배수펌프장 하나에 의존 (한계로 명시)
- 표준데이터 특성상 지자체별 입력 편차 가능

- 공공데이터포털: 전국배수펌프장표준데이터 — https://www.data.go.kr/data/15129436/standard.do

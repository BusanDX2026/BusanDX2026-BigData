# 11. 부산광역시 지하차도 현황 — 지하공간 취약 · 선제 통제 대상

## 데이터 특성
- **형식**: CSV (`부산_지하차도_현황_20250831.csv`), **58개 지하차도**
- **컬럼**: 시설명, 시도, 시군구, 총길이(m), 총폭(m), 총높이(m)
- **인코딩**: CP949
- **기준일**: 2025-08-31
- **좌표 없음** → 시설명 + 시군구로 **지오코딩** 필요 (시설명이 대부분 고유해 매칭 용이. 예: 온천장지하차도, 학장지하차도, 초량제1지하차도)

## 왜 필요한가
- **선제대응의 구체적 운영 대상**: 호우 시 인명피해가 집중되는 곳이 저지대 지하차도. "이 격자/행정동에 지하차도 N개" 또는 "지하차도 통제 필요 지점"으로 산출물에 직접 반영
- **지하공간 취약 레이어 보강**: 지금까지는 건물 지하층수(03번)로만 지하공간 취약을 봤음 → 지하차도가 빠져 있었음. 이 데이터로 통제 대상을 명시적으로 포함
- 지하차도 위치 × 저지대(DEM) × 침수흔적 → "침수 이력 있는 저지대 지하차도" = 최우선 선제 통제

## 활용 방식
- 지오코딩 → 포인트 → 100m 격자/행정동에 조인 (격자별 지하차도 수, 최근접 거리)
- 총길이·총폭·총높이 → 규모 가중 (긴 지하차도일수록 통제 영향 큼)

## 한계·유의사항
- **위경도 미제공** → 지오코딩 정확도에 의존. 매칭 실패 건은 수동 확인
- 자동차단시설(차수판·차단봉) 설치 여부는 이 데이터에 없음 (부산진구만 별도 데이터 존재: data.go.kr, "부산광역시 부산진구_지하차도 차량진입차단시설")
- 침수 이력·펌프 용량 등 방재 정보 없음 → 침수흔적도(05)·DEM(06)과 결합해 위험도 추정

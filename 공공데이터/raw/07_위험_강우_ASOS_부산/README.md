# 07. 종관기상관측(ASOS) 일자료 — 강우 (부산)

## 데이터 특성
- **형식**: CSV
  - `ASOS_일자료_부산_1990-2026_통합.csv` : **4,979행** (10년 단위 5개 병합본)
  - `원본_10년단위/` : 병합 전 원본 5개 (1990-1999 / 2000-2009 / 2010-2019 / 2020-2024 / 2025-2026)
- **지점**: **부산(지점번호 159), 북부산(296)** — 부산의 ASOS는 이 2개뿐. 북부산은 2023년부터 관측
- **기간**: 1990-01-01 ~ 2026-08-31 (**36년+**). 강수 발생일만 기록 (연 약 110~140일)
- **⚠️ 완전연도만 통계에 사용**: 2026은 1~8월 부분 → 재현빈도(연최대) 산정은 **1990~2025 완전연도만**, 2026은 이벤트 매칭·컨텍스트용
- **주요 컬럼**: 일시, 강수 계속시간(hr), 10분 최다강수량(mm), **1시간 최다강수량(mm)**, 일강수량(mm)

## 왜 필요한가
- **위험(Hazard) — 극한강우 빈도 레이어**:
  - 연최대 일강수량 / 연최대 1시간 강수량 → **재현빈도(30·50·100·200년) 산정** (Gumbel 등 분포 적합)
  - "이 지점은 100년 빈도 1시간 강우가 몇 mm인가" → 격자에 부여해 위험 지표로
- **선제대응 임계 강우**: 재해위험지구 데이터의 피해 강우량(DAM_HR_RNFL)과 대조 → "호우 경보 어느 강도부터 선제대응" 판단 근거
- 시범구역 사례분석에서 AI-Hub 강우값(1hr/3hr_rainfall) 검증·보정의 기준

## 한계·유의사항
- **지점이 2개뿐** → 자치구 간 강우 공간차등 불가. → **AWS 15지점(12번)으로 공간분포 보완**
- 재현빈도 산정 시 표본 크기(36년)·분포 적합도 확인. 2026 부분연도 제외
- 강수 발생일만 기록 → 무강수일은 별도 처리(0)

# 01. 행정구역 경계 + 행정구역 통계 (SGIS)

## 데이터 특성
- **형식**: 경계 = SHP(+cpg/dbf/prj/shx), 통계 = CSV
- **구성**
  - `1. 통계/` : 2024년 기준 행정구역 단위 통계 — 인구(성연령별·총인구·인구밀도·평균나이·노령화지수·부양비), 가구(가구총괄·세대구성별), 주택(주택유형별·건축년도별·연건평별), 사업체·종사자(산업분류별)
  - `2. 경계/` : 2025년 2분기 기준 시도(`bnd_sido`) / 시군구(`bnd_sigungu`) / 행정동(`bnd_dong`) 경계
  - `3. 코드집/` : 행정구역↔격자 매핑(`adm_grid_mapping.xlsx`), 통계코드, DB 설계서
- **커버리지**: 전국 (부산 = 시도코드 26)
- **좌표계**: EPSG:5179 (UTM-K / GRS80)
- **기준시점**: 통계 2024년(2025년 발표), 경계 2025년 2분기
- **용량**: 407MB (전국)

## 왜 필요한가
- **결합 기준 단위**: 모든 지표를 이 행정동 경계로 집계 → "행정동 단위 호우 선제대응 우선순위" 산출의 뼈대
- **노출(Exposure) 레이어**: 행정동별 총인구·인구밀도·고령인구비(취약계층) → 같은 침수위험이라도 사람이 많고 취약한 곳을 우선순위 상위로
- 격자 인구(02번)를 행정동으로 검산할 때의 대조값

## 한계·유의사항
- 통계 단위가 행정동까지 → 100m 격자 분석 시에는 02번(격자 인구)을 주로 쓰고 이 데이터는 검산·행정동 집계용
- 경계 좌표계(5179) ≠ 분석 좌표계(5186) → 재투영 필요

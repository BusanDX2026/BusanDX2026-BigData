# 10. 지역 재해위험지구 (자연재해위험개선지구) — 부산 · 검증/비교 baseline

## 데이터 특성
- **형식**
  - `재해위험지구_부산.csv` : 부산 **71건**, 한글 라벨 컬럼 (지구명·유형·등급·법정동코드·시군구·수계·지정면적·거주세대·거주인원·피해이력지수·비용편익값·지정/해제일자·해제여부·지번·지정사유·위험요인)
  - `재해위험지구_부산.json` : 동일 데이터 원본 필드
  - `재해위험지구_전국_원본.json` : 전국 3,049건 (부산 추출 전, 4.7MB)
- **성격**: 시장·군수·구청장이 **상습침수지역 등**을 「자연재해대책법」에 따라 지정·고시한 지구. **행정이 이미 "여기가 위험"이라고 판단한 결과**
- **좌표계 없음 (GEOM 미제공)** → 위치는 법정동코드(`STDG_CD`) + 지번(`MNLNO`/`SUBLOTNO`). 행정동/법정동 단위 매핑 또는 지오코딩 필요
- **주요 코드**
  - 유형코드(`DST_RSK_DSTRCT_TYPE_CD`): **001 = 침수위험지구** (부산 49건), 002 = 해일 등 해안, 003/006 = 기타
  - 등급코드(`DST_RSK_DSTRCT_GRD_CD`): 1(가) / 2(나) / 3(다) — 낮을수록 위험 심각 (가등급 = 인명피해 우려)
  - 해제(`RMV_YMD`): 값 있으면 정비사업 완료 등으로 **지정 해제됨**

## 부산 현황 (핵심)
| 구분 | 건수 |
|---|---|
| 전체 재해위험지구 | 71 |
| 그중 침수 유형(001) | 49 |
| 현재 **유효**(미해제) | 26 |
| **★ 유효 & 침수(001)** | **20** ← 실제 선제대응 검토 대상 |
| 이미 **해제** | 45 (절반 이상 — 과거 상습침수였으나 정비 완료) |
- 지정연도 1993~2026, 유효분은 강서·해운대·북구·사상 등에 분포
- 유효 침수지구 예: 해운대 반여1지구(인원 1,464), 북구 화명체육공원(3,472), 사하 감천2지구(11,000), 사상 초록마을(4,366)

## 왜 필요한가 (이 프로젝트의 "왜 하는가"에 대한 답)
- **피처가 아니라 비교 기준선(baseline)**: 이걸 그대로 우선순위로 쓰면 "행정 지정을 재확인"하는 tautology → 반드시 **우리 지수와 대조하는 용도**
- **3분류 분석** (면접 질문 정면 대응):
  1. 지정에 없는데 우리 지수 높음 → **선제대응 사각지대 (신규 편입 권고)**
  2. 유효 지정인데 우리 지수 낮음 → 이미 대응됐거나 위험 과거형 → 자원 재배치 근거
  3. 유효 지정 & 우리 지수 높음 → 상호 검증
- **거주세대·거주인원**: 노출 보조. **피해이력지수·비용편익값·등급**: 행정의 우선순위 판단 근거(우리 방법론과 비교)
- **45건 해제 사실**: "과거 침수 잦은 곳 = 지금 선제대응 대상"이 아님을 보여주는 직접 증거 (도시는 변한다)

## 한계·유의사항
- **폴리곤 없음** → 위치 정밀도 = 법정동 + 지번 수준. 행정동 단위 분석에는 충분, 격자 단위는 지오코딩 필요
- 거주인원 등 일부 필드 결측 존재
- 지정/해제 기준이 지자체별 편차 (민원·조사 기반)

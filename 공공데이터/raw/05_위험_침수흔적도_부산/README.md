# 05. 침수흔적도 (부산) — 검증 정답 레이어

## 데이터 특성
- **형식**
  - `침수흔적도_부산.geojson` : 부산 **479개 침수흔적 폴리곤** (GIS 바로 사용)
  - `침수흔적도_부산.json` : 동일 데이터 원본 JSON
  - `침수흔적도_전국_원본.json` : 전국 38,003건 (부산 추출 전 원본, 49MB)
- **성격**: **과거에 실제로 침수 피해가 발생한 지역**을 조사·측량한 실측 자료 (2009~2022)
- **좌표계**: **EPSG:3857 (Web Mercator)** → 분석 시 5186 재투영 필요
- **주요 속성**

| 필드 | 의미 |
|---|---|
| FLDN_GRD | 침수흔적 등급 (1~5) |
| FLDN_DOWA | **침수심 (m)** — 부산 0.01~2.45, 평균 0.55 |
| FLDN_AREA | **침수면적 (㎡)** — 부산 합계 약 71㎢ |
| FLDN_YR / FLDN_BGNG_YMD / FLDN_END_YMD | 침수 연도 / 시작·종료일 |
| FLDN_CS_DTL_NM / FLDN_DST_NM | 침수 원인 / 재해명 |
| STDG_SGG_CD | 시군구 코드 |

- **부산 분포**: 2014년 204건·2020년 119건 최다. 16개 구·군 전부. 집중 = 연제 98·기장 62·해운대 46·금정 41·북구 33·사하 31

## 왜 필요한가
- **모델 검증(정답) 레이어**: 우리가 만든 우선순위 지수를 "실제로 침수했던 곳"과 대조 → AUC, 순위상관, 상위 N% 격자의 침수흔적 포착률로 성능 평가
- **면접 대응의 핵심**: "우리 지수 vs 재해위험지구 지정 vs 침수흔적" 3자 비교 → 기존 지정에 없는 신규 위험구역 / 위험이 과거형인 구역 도출
- 격자별 "침수흔적 발생여부(0/1)"를 지도학습(RF/XGBoost) 타깃으로 사용 가능

## 한계·유의사항
- **피처가 아니라 검증·타깃으로만 사용** (danger_level처럼 순환참조 방지). 단, 홍수위험지도(시뮬레이션)와는 독립적이므로 홍수위험지도는 피처로 사용 가능
- 조사·신고된 곳만 기록 → 실제 침수했으나 미기록된 격자는 "정답 0"으로 오라벨 → 검증치(AUC)는 보수적으로 해석
- 좌표계 3857 (다른 레이어는 5186)
